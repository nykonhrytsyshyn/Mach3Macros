  <div align="left">
    <ol>
      <li><b>Locate your Mach3 macros folder:</b><br>
          This is typically <code>C:\Mach3\macros\[Your_Profile_Name]\</code>. Replace <code>[Your_Profile_Name]</code> with the name of your Mach3 profile (e.g., <code>Mach3Mill</code>, <code>Mach3Plasma</code>, etc.).</li>
      <li><b>Download the macro files:</b><br>
          Clone this repository or download individual <code>.m1s</code> files directly.
      </li>
      <li><b>Copy the macros:</b><br>
          Place the downloaded <code>.m1s</code> files (e.g., <code>M123.m1s</code>, <code>M456.m1s</code>) into your Mach3 macros folder.
      </li>
      <li><b>Assign to buttons (Optional):</b><br>
          In Mach3, you can assign these macros to custom buttons on your screenset or call them directly from G-code.
      </li>
    </ol>
