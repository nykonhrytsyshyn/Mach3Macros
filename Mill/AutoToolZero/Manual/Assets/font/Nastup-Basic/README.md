<h1 align="center">Nastup Basic Font</h1>

This folder contains the **Nastup Basic** font, which is used in the educational
manual **"AutoToolZero: Usage Manual"**.

I am not the author of this font.

## About the Font

**Nastup** is a free modular stencil sans serif. The name comes from the
Ukrainian word «Наступ» — which means “Offensive”. It was inspired by stenciled
technical signs on walls, as well as various building details.

A feature of the graphics is in the slices of the bowl on the sides. With such
minimal spacing, this gives a narrower set (especially good with minimal
leading). However, it can be diversified with alternative wide or more open
characters.
